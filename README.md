# Mainthisha S — Black & Gold Premium Portfolio

A refined Next.js portfolio rebuilt around the supplied cinematic black + champagne-gold reference direction.

## Design direction
- Deep black / warm charcoal background
- Champagne-gold accents and atmospheric glow
- Cinematic micro-sparkles and orbit lines
- Glassmorphism cards with restrained borders
- Cormorant Garamond display typography + Hanken Grotesk UI typography
- Clean alignment and consistent spacing
- Hover lift, glow, reveal and magnetic interactions
- Responsive layout for desktop, tablet and mobile

## Main sections
Home · About · Experience · Achievements · Skills · Projects · Certifications · Resume · Contact

The TEXPERIA 3rd Prize is shown as an achievement rather than a certification.

## Run locally
```bash
npm install
npm run dev
```

Then open the local URL shown by Next.js.

## Build
```bash
npm run build
npm start
```

## Notes
The project keeps the existing resume PDF and project detail routes. Replace project artwork with real screenshots whenever available; the current abstract visuals are intentionally lightweight and theme-matched.
